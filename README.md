---

## ✨ Features
✅ **Fast** – Built with React (Vite) for blazing performance  
✅ **Secure** – Data stored safely in MongoDB Atlas  
✅ **Scalable** – Suitable for small to large applications  
✅ **Beautiful UI** – Tailwind CSS for modern styling  

---

## 🛠 Tech Stack

| Layer       | Technology |
|-------------|------------|
| **Frontend** | ⚛️ React (Vite), 🎨 Tailwind CSS |
| **Backend**  | 🟢 Node.js, 🚀 Express.js |
| **Database** | 🍃 MongoDB Atlas |
| **Tools**    | 🔄 Nodemon, 🔐 dotenv, 🌐 CORS |

---

## 🔄 How It Works
1️⃣ User fills the form → Name, Email, Message  
2️⃣ Frontend sends a POST request to `/api/messages`  
3️⃣ Backend validates & stores the data in MongoDB  
4️⃣ User gets a **success or error message instantly**
